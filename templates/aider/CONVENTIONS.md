# Aider Conventions - AI-DLC Framework

- Follow the AI-DLC methodology: Inception & Refinement, Construction, and Operations.
- Mandatory Stop: Refine requirements and architecture first in `aidlc-docs/`; wait for user approval before generating production code.
- Keep modifications scoped to atomic units of work, one at a time.
- Always run the test suite and resolve any test regressions before completing the session.
- Document architectural changes and progress in `aidlc-docs/`.
