# AI-DLC Skill for Antigravity

Follow the AI-DLC 3-phase adaptive lifecycle:
1. **Inception & Refinement**: Determine Full vs Fast Track. For Full Track, produce `aidlc-docs/requirements.md`, `aidlc-docs/architecture.md`, and `aidlc-docs/progress-tracker.md`. Refine trade-offs and questions with the user. **STOP execution turn and obtain explicit human approval before writing ANY implementation code**.
2. **Construction**: Execute one Unit of Work at a time. Write automated tests first/alongside code. Validate before marking completed.
3. **Operations**: Conduct security review, configure logging/observability, and produce `aidlc-docs/operations-guide.md`.
